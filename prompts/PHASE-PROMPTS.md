# Per-phase prompts

Use a phase prompt only after reading `AGENTS.md`, `GOALS.md`, `PLANS.md`, `config.yaml`, and `docs/COURSE-MATERIALS.md`.

## Phase 0 — Bootstrap

Inventory the local course materials, workspace, and available analysis tools. Record chapter scope, constraints, and open questions in `context/`. Do not analyze a target until its repository, revision, scope, and test boundaries have been selected and approved by the team.

## Phase 1 — Course knowledge map

For each in-scope chapter, extract a concise concept-to-evidence map from the provided material. Record chapter/section/page locators and paraphrase rather than reproduce. Note unreadable pages and uncertain mappings.

## Phase 2 — Target screening

Compare a small candidate set using evidence about project scope, license, history, documentation, tests, and safe setup. Present findings and ask the team to choose. Do not select solely from suggested examples.

## Analysis phases

For the selected phase in `PLANS.md`, state the question, method, evidence collected, findings, limits, and next step. Link every material claim to an evidence-log entry. Clearly distinguish a test plan from an executed test and a reconstructed requirement from an original requirement.

## Independent critique

Review one phase without rewriting its conclusion first. List unsupported claims, missing evidence, arithmetic issues, citation gaps, and scope overreach with exact references. The lead agent resolves each item and records the disposition.
