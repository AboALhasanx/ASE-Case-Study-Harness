# Chapter guides

The first release includes a course-material inventory and phase-level concept mapping. Add a focused guide for each chapter as the knowledge extraction phase is completed. A guide should contain:

- course concepts with chapter/section/page references;
- one or more questions to investigate in the target repository;
- expected evidence and a reproducible method;
- common overclaims or limitations;
- reviewer checks.

Do not copy long passages from the course notes. The core case study covers Chapters 1–9. Treat Chapter 10 as supplementary unless the instructor confirms otherwise.
